# Listed Events are ownerless and go through Draft

Listed Events (e.g. COMIFURO, AFA) have no owner account. Each one records its source (added by hand or imported) and starts as a Draft until the Admin publishes it. We rejected letting the future AI scraper log in as the Admin. Then scraped data would look the same as data the Admin checked, and scraping mistakes (wrong dates, duplicates) would go public with no review.
