# Dekakeyou

A place to find events for specific interests (e.g. Japanese pop-culture events) and to join events that people host on the site.

## Language

### People

**Organizer**:
A user who creates and manages Events on the site.
_Avoid_: Host, creator, owner

**Presenter**:
The name of whoever runs a Listed Event in real life (e.g. "Comifuro Committee"), shown as a label. A Presenter has no account on the site.
_Avoid_: Organizer, host, run by

**Attendee**:
A user with an account who joins an Event.
_Avoid_: Participant, guest, member

**Admin**:
The site operator, who manages Listed Events and keeps content appropriate.
_Avoid_: Moderator, superuser

### Events

**Event**:
Something that happens once, at a single start time and end time. Every Event is either a Listed Event or a Hosted Event, and never changes kind.
_Avoid_: Session, occurrence

**Listed Event**:
An Event that happens outside the site (e.g. COMIFURO, AFA), shown for information only. It cannot be joined.
_Avoid_: External event, info event

**Hosted Event**:
An Event run by an Organizer that Attendees can join on the site.
_Avoid_: User event, community event

**Draft**:
An Event not yet visible to the public. Imported Listed Events always start as Drafts.
_Avoid_: Pending, unpublished

**Published**:
An Event visible to the public.
_Avoid_: Active, live, open

**Cancelled Event**:
An Event called off after it was Published, by its Organizer or, for a Listed Event, by the Admin. It stays visible, marked as cancelled.
_Avoid_: Deleted event, closed event

**Removed Event**:
A Hosted Event the Admin took down for breaking the rules. It is hidden from the public and its Reservations are void.
_Avoid_: Deleted event, banned event

**Under Review**:
A Hosted Event hidden from the public until the Admin decides whether to restore it or remove it. Existing Reservations stay, but nobody new can join.
_Avoid_: Flagged, pending, held

**Past Event**:
An Event whose end time has passed.
_Avoid_: Expired event, finished event, archived event

**City**:
The city where an offline Event takes place, chosen from a fixed list. Online Events have none.
_Avoid_: Location, region, area

**Online Event**:
A Hosted Event that happens over a link instead of at a physical venue. The link is shown only to its Attendees.
_Avoid_: Virtual event, remote event

**Cover Image**:
The single picture that represents an Event.
_Avoid_: Banner, thumbnail, poster

**Category**:
One of a small, Admin-managed set of interests that every Event belongs to exactly one of (e.g. Cosplay, J-Music).
_Avoid_: Genre, type, section

**Tag**:
A free, lowercase keyword an Organizer attaches to an Event to make it findable.
_Avoid_: Label, keyword, hashtag

**Capacity**:
The optional maximum number of Reservations a Hosted Event accepts.
_Avoid_: Quota, slots, limit

### Moderation

**Report**:
A logged-in user's complaint that an Event is inappropriate, with a reason.
_Avoid_: Flag, complaint, ticket

**Banned User**:
A user the Admin has locked out of the site, temporarily or permanently, for breaking the rules.
_Avoid_: Suspended user, blocked user

### Joining

**Reservation**:
One Attendee's place in one Hosted Event. It is Active, Withdrawn or Void.
_Avoid_: Registration, participation, booking, ticket

**Withdrawn Reservation**:
A Reservation its Attendee cancelled themselves, which frees the place.
_Avoid_: Cancelled reservation

**Void Reservation**:
A Reservation that ended because its Event was Cancelled or Removed, through no action of the Attendee.
_Avoid_: Invalid, expired, cancelled reservation
